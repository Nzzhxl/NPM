# NPM
NPM (Nzzhxl Package Manager), is a custom-made package manager written in Python.

## How to Use NPM:
**Command Order:** ```Function | Arguments``` (Spaces in Arguments Don't Matter)  
- Case-insensitive Syntax/Functions (**Functions Inputted are Converted to Lowercase**)

### Functions:
- About - Information of NPM
- Help - Prints a simple help message
- Pip - Upgrades pip
- List - Lists installed packages
- Default - Installs a predefined set of libraries
- Install - Installs libraries
- Uninstall - Uninstalls libraries
- Update / Upgrade - Updates specified libraries or the last installed libraries
- Update All / Upgrade All - Updates all installed libraries
- Libraries - Prints a categorized list of commonly used libraries
- Check - Shows information about a library
